# QiZhang 本服官方参考物价库

本库是本服 **Minecraft 26.3、104 个正式服模组、实际启用数据包** 的一个快照，覆盖 7,246 个真实注册物品。物品、802 个物品标签和 8,376 条配方来自隔离服务器加载后的注册表；导出服务器已正常保存退出。它不是通用 Minecraft 数据库，也不是 7,246 项逐项人工审定的价格表。

本次库只提供参考和管理依据，**不自动上架商品，也不默认打开任何商品回收**。服主已有 51 项官方购买基价完整保留。金额单位为余额点，1 铜币等于 1 点；银币与金币换算由经济系统负责。

## 价格如何产生

1. 既有 51 项商品原价是高可信固定锚点。原木、原矿、作物、渔获等自然资源参考其获取难度、生态条件、稀有性和可量产性；这些数值是本服定价假设，不能当作 Mojang 或模组作者的官方货币价格。
2. 普通制造按真实配方逐槽计数，保留输出数量、可选标签和选择的最低参考成本输入。例如，1 个橡木原木得到 4 块木板，计价必须除以 4。木板本身依然受服主禁售规则约束，其成本可以作为其他加工品的推算输入。
3. 参考买价使用 `向上取整((净材料成本 + 燃料 + 工具摊销) × 加工系数 + 每批服务费) ÷ 本产物期望数量)`。普通合成系数 1.12、每批 2 点；切石 1.08、每批 1 点；熔炉 1.15、每批 2 点；篝火 1.12、每批 2 点；农夫锅 1.18、每批 4 点；切割 1.12、每批 2 点；科技加工 1.25、每批 8 点；锻造 1.18、每批 12 点。加工和设备费用是可调整的本服假设，尚未实测机器每小时产能或 FE 电价。
4. 熔炉燃料按 1 个煤炭加工 8 次摊销；高炉、烟熏炉也按燃料与加工同时加速处理。普通合成返还的桶等容器从本次消耗扣除；农夫锅成品容器另计。AE2 的 `inscribe` 模式模具复用并按 1,024 次摊销，`press` 模式照常消耗上下材料。刀具按真实默认耐久摊销；锻造模板视为本次消耗。
5. 去皮、混凝土凝固、装桶等 54 项世界交互参考单独标为 `world_reference`，有独立操作费用。它们是明确列出的本服参考假设，**没有冒充 RecipeManager 中的配方**。去皮和木制建材仍然禁售，参考价用于下游成本计算。
6. GoFish 下界和末地鱼池保留实际资源条目、权重和资源哈希；主世界鱼获条件来自该版 `GoFishLootHandler` 字节码的限定抽取。稀少鱼按维度和相对权重提高参考价，天气、满月、群系、高度要求分别处理。它不是全局“每竿概率”的测量；旧资源条件字段的兼容不确定性也保留在证据中。Naturalist 自然产物先确认真实掉落资源，再按生物难度和供给能力定价。
7. 概率产物保留每项数量和时运 0 的基础概率。农夫切割的时运加成配置为每级 0.1；本库没有把高时运产量伪装成基础产量。多产物成本没有直接扣掉副产物售卖收益，并标记低可信、需人工审核。
8. 没有自然或既有锚点的循环配方不会凭空产生低价。未知参考价不进入可靠成本图，也不传播为其他物品的低价原料。保留生产、加工套利空间，不设“消除所有配方价差”的硬拒绝规则。

## 回收、禁售和修理

- 每个物品有独立的 `official_sell_price` / `default_sell_price`，两者在本次快照相同。可量产物通常约买价的 10%–15%，矿物及普通渔获通常约 20%；取整后至少 1 点，但必须小于购买价。
- 动态回收基准随同一物品的共享市价/官方买价比例缩放，向下取整并至少为 1，最终上限是**本次实际购买价减 1**。实际购买价为 1 时暂停回收。技术物品参考回收为 0。
- 所有条目 `default_sell_enabled=false`、`default_listed=false`。稀有物品默认每日回收额度 0，只供购买；低可信、技术物品和服主禁售条目同样默认回收额度 0。
- `owner_excluded=true` 是独立、不可用手填价绕过的服主禁售标志：低值基础方块、矿锭、矿块、基础压缩块，以及原木以外的木制建材。读取真实 `c:storage_blocks`、`c:ingots` 标签，并识别有精确反向数量配方的基础压缩材料。它与技术物品标志分开保留。
- `technical=true` 包括创造/管理员载体、正常生存不可取物品、编码样板、命名或关联数据决定价值的物品等，禁止普通上架。允许正常流通的条目仍然要求匹配默认组件；此 ID 价格不代表带附魔、容器内容或自定义数据的任意物品价值。
- `eligible=true` 表示有足够依据将官方参考价用于普通商品和修理核价，**并非已经上架**。低可信复杂物品仍有分维度保守高价，但 `eligible=false`，必须人工审核价格与获取路径。手填价不能越过 `owner_excluded` 和 `technical`。
- 可可靠推算的装备允许参考价核定。修理基准为 `向上取整(官方参考买价 × 25% × 缺损耐久 / 最大耐久) + 20`。完整耐久和具体收费执行由经济模块处理，本生成器不执行交易。

## 数据字段和结果

JSON `schema=1`，`items` 按注册 ID 索引。每项保留中文名、买价、独立回收价、分类、两个禁售标志、可信度、默认额度、来源、理由、真实标签、配方 ID、选择的数量成本证据和必要获取维度。`revision` 由全部条目的稳定哈希生成。

本次分类：建筑、矿物、农牧渔业、装备工具、模组物品、稀有物品。名称优先取本服客户端模组简中资源、QiZhangChinese 覆盖资源和原版资源索引 34；15 个缺失/纯缩写键在价格库内显式补全。没有改动玩家客户端语言包。

当前结果：高可信 51，中可信 6,359，低可信 836；可核价 3,758，服主禁售 2,667，技术物品 240。标志之间可能交叉，不能把后三项简单相加当作总数。来源方法为 5,937 项真实配方、368 项自然资源、51 项既有锚点、54 项世界交互参考、50 项不确定配方和 786 项未解决参考。

`QiZhangOfficialPrices.sqlite` 的 `items.record_json` 与 JSON 条目完整一致。`loaded_recipes` 保存 8,376 条配方的 ID、类型、规范化数量输入输出、原始编解码 JSON 的 SHA-256、来源资源 SHA-256；不包含整份上游原始配方文件。原始导出仅留本机审计。中文 CSV 为 UTF-8 BOM，便于表格软件读取。

## 可复现与验证

生成器支持显式参数，不含固定本机绝对路径、私人玩家、服务器地址或凭证。默认相对路径适合原项目的工作目录；独立模块使用以下参数指向本地输入：

```text
python generate_prices.py --assets <Minecraft-assets> --dump-report <runtime-result.json> --client <client-candidate> --server-mods <actual-server-mods> --anchors <market-config.json> --output <database-directory> --resource-output <resource-json-target>
python verify_prices.py --database <database-directory> --dump-report <runtime-result.json> --anchors <market-config.json> --resource <resource-json-target>
```

导出回执须指向本机实际导出清单，并带正常退出结果和文件哈希。生成器会核对全部原始文件；GoFish 已审查的注入类哈希变化时中止，要求重新核对条件。更换模组、数据包、配方或既有锚点后，应重新导出、生成和验证，不直接把本服数值当作其他版本的完成品。

41 项数据 QA 覆盖全注册 ID、51 锚点、价格/回收边界、默认开关、稀有额度、服主禁售、技术/组件保护、装备、真实配方槽位和产量、概率与容器、模具复用、循环无根、未知输入不传播、SQLite/JSON/CSV 一致性以及发布数据的本机地址清洁。它是数据和成本图验证，**不是正式服交易或长期经济稳定性的实机测试**。运行集成由主经济模块继续完成。

## 来源与许可边界

本项目的定价规则、生成器和验证器以 GPL-3.0-only 提供。Minecraft 与各模组的名称、注册 ID、配方关系及必要数量事实仍来自各自上游；不宣称这些上游内容由本项目原创，也不将其许可统一改为 GPL。发布清单不含原版资源包、模组 JAR、完整语言文件、原始完整配方、原始运行日志、测试世界或私人导出回执。根目录的正式许可和第三方声明应随独立项目一起提供。

## 可种植种源校正

竹子、杜鹃花丛、盛开的杜鹃花丛、绯红菌、诡异菌、模组椰树幼苗和模组杜鹃花属于可繁殖植物，采用精确ID例外，不再因木材名称而禁售。未扩展到木制建材、种子袋或作物压缩箱。椰树幼苗、模组杜鹃花使用实际树苗继承/催生行为审核后的16、12参考买价。对应商品增量及回收额度见 planting-stock.json。
