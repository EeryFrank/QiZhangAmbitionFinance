# QiZhangAmbitionFinance · 七章的野心金融

面向 Minecraft Java Edition 26.3 / NeoForge 的服务器金融模组，配套可选的中文生活菜单与传送服务。由服务器保存余额、计算批次价格、签发交易报价并提交账本，客户端展示服务器确认的结果。

当前版本为 **0.1.0-preview.1**。目前优先完成本服可玩性与运行验证，其他游戏版本和经济生态对接列入后续计划。仓库准备与本地构建不代表已经发布 GitHub Release。

**本项目不是 Minecraft 官方产品，未获 Mojang 或 Microsoft 批准，也不与其关联。** 项目由 EeryFrank 维护。

## 当前模块

| 模块 | 用途 | 注册 ID |
| --- | --- | --- |
| `finance` | 金融核心：余额、实体币、商店、独立回收基准、参考价格库、管理接口和账本 | `cozylife_economy` |
| `cozylife-integration` | 可选生活扩展：中文侧边菜单、家园、玩家传送及可选 Waystones 收费 | `qizhang_cozy_services` |

核心没有 Waystones、Balm 或 Shogi 编译依赖。扩展依赖核心；其 Waystones 适配是可选功能，构建所用版本见[构建说明](docs/BUILDING.md)。仓库与输出模组不会内嵌这些第三方模组，也不包含 Minecraft 客户端、服务器或完整整合包。

## 已实现的功能

- 铜币、银币、金币对应 1、100、10,000 点余额；手持钱币右键存入账户，可在兑换页取回实体币。
- 服务器商店支持分类、买入与回收、服务端批次报价、市场随逐件交易浮动及每日回收数量额度。
- 买入和回收使用独立基准；回收价受实际买价减 1 的限制，买价为 1 时暂停回收。正常种植、生产及加工利润不是统一禁止项。
- 新商品可显式使用本服参考价格，也可人工定价；技术物品和禁售物品仍由服务器规则检查。参考价格库不会自动把所有物品上架。
- 管理员可调整商品、规则、权限与金融档位；经济概况区分余额、消费、发行及实体币和余额之间的形态转换。
- 邮箱投递实体币与主手装备修理；修理使用一次性报价并由服务器核对物品状态。
- VIP 每次购买或续期增加 7 天，剩余不超过 21 天时可续、最多累计 28 天；每次成功购买或续期赠送 1 次永久补签机会。
- 签到按北京时间日期结算，支持连续复利、有效 VIP 奖励加成、历史日历补签与只领取一次的连续里程碑银币邮件。正常签到当天点击领取，补签须单独确认。
- `qizhang.ambitionfinance.api.FinanceApi` 提供服务器线程上的余额和交易接口。带请求 UUID 的核心交易可识别同一请求重放；第三方调用仍须遵守接口约定。
- 生活扩展提供默认 `V` 键菜单、一个可覆盖设置的家和玩家传送申请；菜单提示显示当前实际绑定，可在按键设置中自定义。收费预先显示；回家、玩家传送和可选 Waystones 收费由服务器执行。

内置参考价格库来自本服注册物品、配方和标签快照，当前包含 7,246 个物品记录。它是本服的参考定价资料，不是覆盖所有版本、所有模组的通用权威目录；估算值、低置信度记录和具体禁售规则需由服主审核。“本服官方价”指本服务器维护的价格，与 Mojang 定价无关。

`pricing-profile-cozylife` 保存对应的精简定价资料与追溯说明；51 项原价锚点不代表其余数千项已经逐件人工审价。上游注册 ID、名称和配方事实的来源声明见第三方说明。

## 安装与旧数据边界

目标环境为 **Minecraft 26.3、NeoForge 26.3.0.50-beta、Java 25**。实体币属于自定义物品，使用本模组的服务器及客户端均需安装对应核心；使用完整菜单和生活服务时再安装配套扩展。

两个生产 JAR 分别从 `finance/build/libs/` 与 `cozylife-integration/build/libs/` 取得。`-sources.jar` 和 `-javadoc.jar` 是开发资料，不放进 `mods`。替换原本服 `QiZhangEconomy` 时不要同时保留两个注册 `cozylife_economy` 的 JAR。

为避免改变既有币物品，本预览保留：

```text
cozylife_economy:copper_coin
cozylife_economy:silver_coin
cozylife_economy:gold_coin
```

既有账本命名也保留兼容路径。旧账户副本迁移和正常重启已在本地隔离测试服验证；这不等于所有旧存档、正式服玩家或其他整合包均已验证。更换服务器时仍应按管理员指南保存原账本与对应玩家数据。
